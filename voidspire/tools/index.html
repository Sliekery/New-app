HOW A THING GETS FROM HERE INTO THE GAME

  1. Make it in the tool. It saves itself in this browser as you go — nothing is uploaded anywhere.
  2. Press HAND OFF. That copies the creation together with a note saying what it is and which file it belongs in, and saves the same thing as a file.
  3. Paste or send it to me. I wire it up, test it and push it.
  4. The build number on this page goes up. That is how you know it landed.

Moving between a phone and a desktop: the tools save per browser and per device, and nothing syncs. BACKUP ALL takes every tool's work as one file; RESTORE puts it back on the other device. A run of the game in progress is not in that file — it is saved separately and stays on the machine it was played on.
